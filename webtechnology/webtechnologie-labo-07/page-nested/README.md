# page-nested

* Kopieer je oplossing van `page-layout` en voeg een nav-element toe binnen de header
* Verwijder de 5px padding van elk element
* Voeg een ongeordende lijst toe in de nav, met daar in 3 list-items. Plaats hierbinnen 3 links die naar nergens (`#`) verwijzen.
* Zorg ervoor dat de ongeordende lijst op zijn beurt een grid-parent wordt
* Zorg ervoor dat de ongeordende lijst de background-color `teal` krijgt. 
* De grid-items zijn telkens 70px breed.
* Zorg ervoor dat het nieuwe grid rechts uitgelijnd is.
* Geef de 3 grid-children een gap van 3rem.
