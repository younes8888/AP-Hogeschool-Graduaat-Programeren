# portfolio-grow

* Kopieer je oplossing van `portfolio`
* Zet `flex-grow` op `1` bij elk flex-item. Je houdt de `flex-basis` van `300px`, zodat de items de rij opvullen en de laatste image, die als enige op zijn lijn staat, de volledige breedte van de main inneemt. Dit is het kaartenraster-patroon: `flex: 1 1 300px`
* Zorg dat de laatste image breed genoeg is (1000px) maar niet te hoog (bv. 200px)
