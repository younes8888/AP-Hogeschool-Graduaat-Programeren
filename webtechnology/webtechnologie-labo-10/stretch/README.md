# stretch

Bouw de animatie uit het filmpje na met HTML en CSS.

* Plaats één element in je `body` en geef het een `id`.
* Zet het element mooi in het midden van het scherm. Gebruik hiervoor flexbox op de `body` met een hoogte van `100vh`.
* Het element is 200px breed, 80px hoog en heeft `lightseagreen` als achtergrondkleur.
* Schrijf een `@keyframes`-animatie die het element horizontaal uitrekt en weer laat krimpen. Gebruik hiervoor `transform: scaleX(...)`.
* De animatie duurt 1 seconde, herhaalt 5 keer en gebruikt `ease` als timing-functie.
