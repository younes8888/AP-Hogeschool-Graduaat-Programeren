# hover

Bouw de transitie uit het filmpje na met HTML en CSS.

* Plaats één element in je `body` en geef het een `id`.
* Zet het element mooi in het midden van het scherm. Gebruik hiervoor flexbox op de `body` met een hoogte van `100vh`.
* Het element is een rood vierkant van 200px op 200px.
* Wanneer de gebruiker er met de muis over gaat, verandert het vierkant in een blauwe cirkel. Gebruik hiervoor de `:hover` pseudo-class met `border-radius` en `background-color`.
* De overgang verloopt vloeiend en duurt 2 seconden. Gebruik hiervoor `transition` en let op: de transitie zet je op het element zelf, niet op de `:hover`-regel, zodat ze in beide richtingen werkt.
